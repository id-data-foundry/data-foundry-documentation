# Image-to-Image
Image-to-image lets you transform an existing picture using a text prompt—for example, adding an element, changing the artistic style, or adjusting the lighting while preserving the original composition. In `local-ai.js`, `foundry.imageToImage` accepts a `File`, an `<img>` element, a `<canvas>`, or a URL directly. Use the `strength` parameter to control how closely the output follows the original image (`0.0` stays close to the input; `1.0` allows a full reinterpretation).
