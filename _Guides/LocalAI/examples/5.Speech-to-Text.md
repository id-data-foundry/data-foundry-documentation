# Speech-to-Text
Not every interaction allows you to manually type text. Sometimes it just feels more natural to talk to your design. This example demonstrates DataFoundry's sub-100ms real-time live microphone streaming speech-to-text via Sherpa-ONNX (`foundry.transcribeLive`).

> For transcribing pre-recorded audio or video files (with model selection and speaker diarization), use the built-in [Transcription Tool]({% link _Guides/Tools/Transcription.md %}) on the platform or `foundry.transcribeFile` in the [JS API Reference]({% link _Reference/LocalAI/JSAPI.md %}).
