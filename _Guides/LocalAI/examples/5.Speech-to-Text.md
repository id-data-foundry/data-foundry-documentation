# Speech-to-Text
Not every interaction allows you to manually type text. Sometimes it just feels more natural to talk to your design. DataFoundry provides two speech-to-text models: sub-100ms real-time live microphone streaming via Sherpa-ONNX, and high-accuracy longform batch audio file transcription via Parakeet TDT / Whisper.
