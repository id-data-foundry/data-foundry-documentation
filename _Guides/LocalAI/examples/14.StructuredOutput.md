# Structured Output (JSON)
Sometimes you want the LLM to provide its answer not as plain text, but as a structured JSON object. This is especially useful if you want to use the output directly in your code, for example to control a device via OOCSI or update a dashboard. 

In this example, we instruct the LLM to output exclusively JSON using a system prompt and the `responseFormat` parameter. We then take the resulting JSON and send it over the OOCSI network.
