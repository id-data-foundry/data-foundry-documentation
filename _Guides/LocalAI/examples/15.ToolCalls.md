# Tool Calls (Function Calling)
Tool Calling (formerly known as Function Calling) is a powerful feature that allows the LLM to interact with your application's code. Instead of just generating text, the model can decide to "call" a function you've defined, providing the necessary arguments in a structured format.

In this example, we define a tool for sending OOCSI messages. When you ask the assistant to send data, it will request a tool call instead of just replying with text. Your code then executes that tool call locally.
