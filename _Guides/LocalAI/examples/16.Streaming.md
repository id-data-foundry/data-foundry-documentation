# Streaming Responses
Streaming allows you to receive parts of the AI's response as they are generated, rather than waiting for the entire response to be finished. This significantly improves the user experience by reducing the perceived wait time.

In the Data Foundry Local AI library, you can enable streaming by setting the `stream` parameter to `true`. You can also provide an `onChunk` callback function that will be called every time a new piece of text is received.

### Key Parameters
- `stream`: Set to `true` to enable streaming.
- `onChunk`: A callback function that receives the new text chunk as a string.
- `resultElementSelector`: If provided, the library will automatically append chunks to this element.
