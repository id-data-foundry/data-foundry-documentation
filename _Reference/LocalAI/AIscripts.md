# Using the AI APIs in scripts

The most useful API from the DF scripting perspective is the **chat** which generates textual output. Let's have a look at how this works.

## Completion example

A *completion* (or chat) needs a list of messages and the AI will return a generated response based on those messages. [Read more about chat completions](https://platform.openai.com/docs/guides/chat-completions) in the OpenAI API docs. You will also find useful tips and tricks how to craft a good prompt.

Let's try a first example with LocalAI. We want to generate a tagline for a flower shop.

````Javascript
let result = DF.api("ai", {
  "task": "chat",
  "messages": [{ "role": "user", "content": "Write a tagline for a flower shop." }]
});

// The result is a JSON string, so we parse it first
let parsed = JSON.parse(result);
DF.print(parsed.content);
````

### Return value

The `DF.api` function returns a simplified, flat JSON object (as a string) which makes it easy to access the most important information:

````json
{
  "role": "assistant",
  "content": "Flowers for a global audience.",
  "finishReason": "stop",
  "cost": 18
}
````

- **`role`**: The role of the speaker (usually "assistant").
- **`content`**: The actual text generated by the AI.
- **`finishReason`**: Why the generation stopped (e.g., "stop" for success, or "length" if it hit the token limit).
- **`cost`**: The number of tokens used for this request.

## Chat example

The chat completion API endpoint can be used to generate a new reply to an existing chat, i.e., a list of prior messages. Every message has a `role` (who is speaking) and `content` (what are they saying).

The following example shows a simple continuation of a chat:

````Javascript
let result = DF.api("ai", {
  "task": "chat",
  "messages": [
    { "role": "system", "content": "You are a helpful assistant." },
    { "role": "user", "content": "Who won the world series in 2020?" },
    { "role": "assistant", "content": "The Los Angeles Dodgers won the World Series in 2020." },
    { "role": "user", "content": "Where was it played?" }
  ]
})
DF.print(result)
````

## API concepts

### Automatic API Key Injection

When running scripts within Data Foundry, the system **automatically injects your project's default API key** into all `DF.api` calls. You do not need to provide an `api_token` manually.

If you wish to use a specific API key, you can still override the default by providing the `api_token` field:

````Javascript
let result = DF.api("ai", {
  "api_token": "your-personal-key", 
  "task": "chat",
  "messages": [...]
})
````

### API reference

There are more options available than explained above. We generally follow the OpenAI parameter names.

All DF API requests follow the structure: 

````Javascript
let result = DF.api("ai", {
  "task": "chat",
  "messages": [...], // used for chat tasks
  ... more parameters...
})
````

#### Chat Completion requests

You can use the following parameters to fine-tune the AI's behavior:

- **`temperature`** (number): Controls randomness. Values closer to 1.0 make the output more creative and varied, while values closer to 0.0 make it more deterministic and focused. (Default: 0.7)
- **`max_tokens`** (integer): The maximum number of tokens to generate in the completion. Use this to prevent very long responses and control costs.
- **`presence_penalty`** (number): A value between -2.0 and 2.0. Positive values penalize new tokens based on whether they have appeared in the text so far, increasing the model's likelihood to talk about new topics.
- **`frequency_penalty`** (number): A value between -2.0 and 2.0. Positive values penalize new tokens based on their existing frequency in the text so far, decreasing the model's likelihood to repeat the same line verbatim.
